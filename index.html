Predicting Patient Churn in Healthcare

When patients stop seeing their provider, their health gets worse and the clinic loses revenue. We used R to find which factors drive churn and to test whether a model could flag at-risk patients early.

Why this topic. Working at Alberta Health Services in the Foothills Medical Centre made me want to look into patient churn in healthcare.

Dataset. The dataset we used is from Kaggle. It's a U.S.-based dataset of 2,000 patients and includes demographic, behavioural, satisfaction and financial variables used to analyze patient churn.

Patient Churn in Healthcare 1 / 15

How I used R

  1. 1
    Prepare the data

    Converted the churn flag, gender, state, specialty and insurance type to factors, turned the last-interaction date into a number, and dropped the patient ID.

    data$Churned <- as.factor(data$Churned)
data$PatientID <- NULL
  2. 2
    Find the drivers

    Ran three methods on every variable and kept the ones they agreed on: logistic regression coefficients, random forest importance (mean decrease in Gini) and LASSO, which shrinks weak variables to zero.

    lasso <- cv.glmnet(x, y, family = "binomial", alpha = 1)
coef(lasso, s = "lambda.min")
  3. 3
    Build three models

    Each model used the top drivers from step 2. The KNN model used visits in the last year in place of days since last visit. Pick a model to see its code.

    300 trees on a 70/30 train/test split, with variable importance turned on.

    # Keep the selected drivers + target
df_reduced <- df[, c("Tenure_Months", "Days_Since_Last_Visit",
                     "Avg_Out_Of_Pocket_Cost", "Overall_Satisfaction",
                     "Distance_To_Facility_Miles", "Churned")]
df_reduced$Churned <- as.factor(df_reduced$Churned)

# 70/30 train/test split
set.seed(123)
train_index <- sample(1:nrow(df_reduced), 0.7 * nrow(df_reduced))
train_data <- df_reduced[train_index, ]
test_data  <- df_reduced[-train_index, ]

# Train the random forest
rf_model <- randomForest(
  Churned ~ ., data = train_data,
  ntree = 300,
  mtry = floor(sqrt(ncol(train_data) - 1)),
  importance = TRUE
)

# Predict classes and churn probabilities
rf_pred <- predict(rf_model, newdata = test_data)
rf_prob <- predict(rf_model, newdata = test_data, type = "prob")[, "1"]

    Binomial GLM on a 70/30 split. A patient is flagged as churn when the predicted probability is 0.5 or higher.

    # 70/30 train/test split
set.seed(55)
idx   <- sample(n, size = 0.70 * n)
train <- df[idx, ]
test  <- df[-idx, ]

# Logistic regression on the top drivers
model <- glm(
  Churned ~ Overall_Satisfaction + Days_Since_Last_Visit +
    Distance_To_Facility_Miles + Tenure_Months +
    Avg_Out_Of_Pocket_Cost,
  data = train, family = "binomial"
)
summary(model)

# Probability of churn, then classify at 0.5
test$prob <- predict(model, newdata = test, type = "response")
test$pred <- ifelse(test$prob >= 0.5, 1, 0)

# Accuracy and confusion matrix
mean(test$pred == test$Churned)
confusionMatrix(test$pred, test$Churned)

    k = 5 on an 80/20 split. Features are standardized using the training set's mean and spread, since KNN works on distances.

    # 80/20 train/test split
set.seed(123)
train_index <- sample(1:nrow(df_reduced), 0.8 * nrow(df_reduced))
train_data <- df_reduced[train_index, ]
test_data  <- df_reduced[-train_index, ]

x_train <- train_data[, -which(names(train_data) == "Churned")]
x_test  <- test_data[, -which(names(test_data) == "Churned")]
y_train <- train_data$Churned
y_test  <- test_data$Churned

# Standardize with the training set's centre and scale
x_train_scaled <- scale(x_train)
x_test_scaled  <- scale(x_test,
  center = attr(x_train_scaled, "scaled:center"),
  scale  = attr(x_train_scaled, "scaled:scale"))

# Classify each test patient by its 5 nearest neighbours
knn_pred <- knn(train = x_train_scaled, test = x_test_scaled,
                cl = y_train, k = 5, prob = TRUE)

# Convert vote share into a churn probability
knn_raw_prob <- attr(knn_pred, "prob")
knn_prob <- ifelse(knn_pred == "1", knn_raw_prob, 1 - knn_raw_prob)
  4. 4
    Evaluate

    Built a confusion matrix for each model and calculated accuracy, sensitivity, specificity and AUC with pROC. Sensitivity mattered most, because a missed churner is a patient lost without any outreach.

    cm <- table(Predicted = rf_pred, Actual = test_data$Churned)
accuracy    <- sum(diag(cm)) / sum(cm)
precision   <- tp / (tp + fp)
recall      <- tp / (tp + fn)   # sensitivity
specificity <- tn / (tn + fp)
auc(roc(as.numeric(as.character(test_data$Churned)), rf_prob))

What drives churn

Days since last visit
Churn climbs above 70% after about a year of inactivity
Overall satisfaction
~75–80% churn at ratings 1–2, ~58–60% at 4–5
Tenure
~70–75% churn in the first 3 years, falling to ~58%
Distance to facility
~64% nearby, rising to ~73% at 30–40 miles
Out-of-pocket cost
Small rise with cost, no clear threshold

Age, gender, state, insurance type and last interaction date were weak predictors.

Model results

ModelAccuracySensitivitySpecificity
Random forest68.5%90.0%18.3%
Logistic regression68.2%10.6%92.9%
KNN (k = 5)64.0%82.6%20.2%

Random forest caught 9 in 10 churners, so we recommended it for flagging high-risk patients. About 68% of the records were churners, so all three models leaned toward one class. Balancing the classes and adding clinical features are the next steps.
